# Свой сервер: VPN + Claude Code

Один VPS в Нидерландах выполняет две независимые задачи:

```
 твои ~10 устройств ──VLESS+Reality (443/tcp)──▶ ┌──────────── VPS (Амстердам) ────────────┐
                                                 │ Xray        — VPN                        │
 телефон: приложение Claude ──▶ claude.ai ◀───── │ Claude Code — работает здесь, в tmux,    │
                                                 │               на связи через Remote Control │
 ноутбук/телефон ──SSH (ключ)──────────────────▶ │ ufw · fail2ban · автообновления          │
                                                 └──────────────────────────────────────────┘
```

- **VPN** нужен только твоим устройствам. Claude Code на сервере обходится без него и ходит в интернет напрямую.
- **Claude Code** работает на сервере. С телефона ты управляешь им через приложение Claude (Remote Control). SSH с телефона при этом не нужен.

---

## 0. Что нужно заранее

| Что | Зачем |
|---|---|
| SSH-ключ | Вход на сервер. Пароли будут отключены |
| Подписка Claude **Pro / Max** | Нужна для Remote Control (управления с телефона). С API-ключом Remote Control **не работает** |
| Нахождение в [поддерживаемой стране](https://www.anthropic.com/supported-countries) | Официальное требование Claude Code. Проверяется, где находишься **ты**, а не сервер |
| VPS: Ubuntu 24.04, **2 vCPU / 4 ГБ RAM**, ~40 ГБ диска | 4 ГБ RAM — официальный минимум для Claude Code. Самому VPN хватило бы 512 МБ |

### SSH-ключ

На компьютере (macOS/Linux/Windows PowerShell):

```bash
ssh-keygen -t ed25519 -C "my-vps"
cat ~/.ssh/id_ed25519.pub     # эту строку вставишь при создании сервера
```

На телефоне ключ генерирует сам SSH-клиент: Termius (iOS/Android) или Blink (iOS). Публичную часть добавишь на сервер позже (см. раздел 5).

## 1. Заказ сервера

Локация Amsterdam есть у DigitalOcean, Vultr и Akamai (Linode). Все трое принимают американские карты. Vultr исторически принимал и криптовалюту, проверь в разделе Billing. Тариф 2 vCPU / 4 ГБ у них стоит порядка $20–25 в месяц. Точную цену смотри при заказе.

Если Нидерланды не принципиальны, Hetzner (Германия, Финляндия) даёт такие же 4 ГБ в несколько раз дешевле.

При создании сервера:
1. Образ: **Ubuntu 24.04 LTS**.
2. Локация: **Amsterdam**.
3. Authentication: **SSH key**, вставь строку из `id_ed25519.pub`.
4. Если у провайдера есть облачный файрвол, открой в нём **22/tcp** и **443/tcp**.

## 2. Установка (одна команда)

```bash
ssh root@<IP-сервера>

apt-get update && apt-get install -y git
git clone -b claude/vpn-server-netherlands-a5dmiz https://github.com/efim-armand-ai/ai-prompt-builder-bot.git
cd ai-prompt-builder-bot/server

ADMIN_USER=dev VPN_DEVICES="iphone ipad mac android laptop" bash setup.sh
```

> После слияния ветки в `main` флаг `-b claude/vpn-server-netherlands-a5dmiz` можно убрать.

Скрипт по очереди:
1. **Защищает сервер.** Создаёт пользователя `dev` с sudo по паролю. Включает вход только по ключу, запрещает вход под root. Настраивает файрвол (открыты только SSH и 443), fail2ban, автообновления безопасности, BBR и swap.
2. **Ставит VPN.** Устанавливает Xray с VLESS + Reality и создаёт по устройству на каждое имя из `VPN_DEVICES`, с QR-кодами.
3. **Ставит Claude Code.** Устанавливает его для пользователя `dev` и добавляет команды `claude-remote` и `claude-shell`.

В конце скрипт печатает **пароль для sudo**. Сохрани его в менеджер паролей.

Необязательные настройки (переменные перед `bash setup.sh`):

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `ADMIN_USER` | `dev` | Имя твоего пользователя |
| `SSH_PORT` | `22` | Порт SSH. Нестандартный порт уменьшает шум в логах |
| `VPN_DEVICES` | `device1` | Устройства для VPN через пробел |
| `VPN_PORT` | `443` | Порт VPN. Лучше оставить 443 |
| `REALITY_SNI` | `www.microsoft.com` | Сайт, под HTTPS-трафик которого маскируется VPN |
| `CLONE_REPO` | — | Git-репозиторий, который склонировать в `~/projects` |
| `SKIP_CLAUDE` | — | `1`: не ставить Claude Code |

Шаги можно запускать и по отдельности: `01-harden.sh`, `02-vpn.sh`, `03-claude-code.sh`. Все скрипты можно перезапускать: ключи VPN и устройства сохраняются. `setup.sh` копирует скрипты в `/opt/vps-setup`, чтобы они были доступны пользователю `dev` для обслуживания (клон в `/root` ему не виден).

## 3. Проверь вход ДО закрытия окна

Вход под root по SSH уже отключён. В **новом** окне терминала:

```bash
ssh dev@<IP-сервера>          # или: ssh -p <SSH_PORT> dev@<IP>
sudo whoami                   # спросит пароль из шага 2 и ответит root
```

Только когда это сработало, закрывай старое окно.

## 4. VPN на устройствах

У каждого устройства свой ключ. Потерял телефон: `sudo vpn remove iphone`, остальные устройства продолжают работать.

```bash
sudo vpn add ipad       # новое устройство: ссылка + QR-код прямо в терминале
sudo vpn show iphone    # показать ещё раз
sudo vpn link iphone    # только ссылка (скопировать и отправить себе)
sudo vpn list           # все устройства
sudo vpn remove iphone  # отключить устройство
sudo vpn status         # состояние сервера
```

Клиенты (все умеют VLESS + Reality и импорт по ссылке или QR):

| Платформа | Приложения |
|---|---|
| iPhone / iPad / Mac (M1+) | Streisand, v2RayTun, Happ, FoXray |
| Android | v2rayNG, Hiddify, Happ |
| Windows | Hiddify, v2rayN |
| Linux | Hiddify |

В приложении нажми «+», затем «Импорт из буфера» или «Сканировать QR» и включи подключение. Проверка: [ifconfig.me](https://ifconfig.me) должен показать IP сервера.

## 5. Claude Code: работа с телефона

Один раз, зайдя по SSH как `dev`:

```bash
claude                 # набери /login → открой ссылку на телефоне/ноутбуке,
                       # войди подпиской Claude, вставь код обратно → /exit
claude-remote          # ответь y на «Enable Remote Control?» и «Trust …?»
                       # нажми пробел → QR-код → отсканируй телефоном
                       # выйти из tmux, не останавливая Claude: Ctrl+B, затем D
sudo systemctl enable claude-remote   # поднимать Remote Control после перезагрузки
```

Дальше SSH не нужен: открой приложение Claude, раздел **Code**, и выбери сессию сервера. Команды выполняются на сервере, в папке `~/projects`.

Запасной путь через SSH (Termius или Blink на телефоне):

```bash
claude-shell           # Claude Code в tmux; связь оборвалась → зайди снова и набери claude-shell
```

Добавить ключ телефона на сервер: скопируй публичный ключ из Termius или Blink, затем выполни на сервере `nano ~/.ssh/authorized_keys`, вставь ключ новой строкой и сохрани.

## 6. Обслуживание

| Задача | Команда |
|---|---|
| Обновления безопасности | ставятся сами каждый день |
| Перезагрузка после обновления ядра (раз в месяц) | `sudo reboot`. VPN и Remote Control поднимутся сами |
| Обновить Xray | `sudo bash /opt/vps-setup/02-vpn.sh` |
| Claude Code | обновляется сам; вручную: `claude update` |
| Кто ломится по SSH | `sudo fail2ban-client status sshd` |
| Логи VPN | `sudo journalctl -u xray -n 50` |

## 7. Безопасность

- Пароль для sudo нужен специально. Claude Code работает под `dev` и **не может** молча выполнить `sudo`: пароль он не знает. Не делай `NOPASSWD` и не запускай Claude под root.
- Не запускай Claude с `--dangerously-skip-permissions`, пока на сервере лежат ключи и токены, которые жалко потерять.
- `/usr/local/etc/xray/reality.env` и `config.json` содержат приватный ключ VPN. Никому их не отправляй.
- Все секреты создаются на сервере. В репозитории их нет, поэтому скрипты можно держать публичными.

## 8. Если что-то не работает

| Симптом | Что делать |
|---|---|
| VPN подключается, но сайты не открываются | Переимпортируй свежую ссылку (`sudo vpn show <имя>`): после смены ключей или сайта маскировки старые ссылки не работают |
| VPN не подключается вообще | `sudo vpn status`, `sudo journalctl -u xray -n 50`. Проверь облачный файрвол провайдера (443/tcp) |
| VPN работает дома, но не в мобильной сети (или наоборот) | Смени сайт маскировки: `sudo REALITY_SNI=www.apple.com bash /opt/vps-setup/02-vpn.sh`. Ссылки устройств поменяются, импортируй их заново через `sudo vpn show <имя>` |
| Соединение «замирает» после первых килобайт | Сеть, из которой ты подключаешься, режет диапазон IP этого хостинга. Помогает только сервер у другого провайдера |
| Потерял доступ по SSH | Веб-консоль провайдера (VNC/Console) → войди под root → проверь `/etc/ssh/sshd_config.d/00-hardening.conf` |
| `claude-remote` пишет об ошибке входа | Выполни `claude`, затем `/login`. Нужен вход подпиской Pro/Max, а не API-ключом |
