# Свой сервер: VPN + Claude Code

Один VPS в Нидерландах выполняет две независимые задачи:

```
 iPhone ×3, iPad ×3, Pixel,  ─VLESS+Reality (443/tcp)─▶ ┌────────── VPS (Амстердам) ──────────┐
 ноутбук, компьютер                                     │ Xray       — VPN для устройств      │
                                                        │ AmneziaWG  — туннель для роутера    │
 домашний роутер (ТВ ×2 и др.) ─AmneziaWG (UDP)───────▶ │ Claude Code — в tmux, Remote Control│
                                                        │ ufw · fail2ban · автообновления     │
 телефон: приложение Claude ──▶ claude.ai ◀──────────── │                                     │
 ноутбук/телефон ──SSH (ключ)─────────────────────────▶ └─────────────────────────────────────┘
```

- **VPN** нужен только твоим устройствам. Claude Code на сервере обходится без него и ходит в интернет напрямую.
- **Claude Code** работает на сервере. С телефона ты управляешь им через приложение Claude (Remote Control). SSH с телефона при этом не нужен.

---

## 0. Что нужно заранее

| Что | Зачем |
|---|---|
| SSH-ключ | Вход на сервер. Пароли будут отключены |
| Подписка Claude **Pro / Max** | Нужна для Remote Control (управления с телефона). С API-ключом Remote Control **не работает** |
| Нахождение в [поддерживаемой стране](https://www.anthropic.com/supported-countries) | Официальное требование Claude Code. Проверяется, где находишься **ты**, а не сервер |
| VPS: Ubuntu 24.04, **2 vCPU / 4 ГБ RAM**, ~40 ГБ диска | 4 ГБ RAM — официальный минимум для Claude Code. Самому VPN хватило бы 512 МБ |

### SSH-ключ

На компьютере (macOS/Linux/Windows PowerShell):

```bash
ssh-keygen -t ed25519 -C "my-vps"
cat ~/.ssh/id_ed25519.pub     # эту строку вставишь при создании сервера
```

На телефоне ключ генерирует сам SSH-клиент: Termius (iOS/Android) или Blink (iOS). Публичную часть добавишь на сервер позже (см. раздел 5).

## 1. Заказ сервера

Локация Amsterdam есть у DigitalOcean, Vultr и Akamai (Linode). Все трое принимают американские карты. Vultr исторически принимал и криптовалюту, проверь в разделе Billing. Тариф 2 vCPU / 4 ГБ у них стоит порядка $20–25 в месяц. Точную цену смотри при заказе.

Если Нидерланды не принципиальны, Hetzner (Германия, Финляндия) даёт такие же 4 ГБ в несколько раз дешевле.

При создании сервера:
1. Образ: **Ubuntu 24.04 LTS**.
2. Локация: **Amsterdam**.
3. Authentication: **SSH key**, вставь строку из `id_ed25519.pub`.
4. Если у провайдера есть облачный файрвол, открой в нём **22/tcp**, **443/tcp** и UDP-порт AmneziaWG. Порт выбирается случайно, скрипт напечатает его в конце установки. Можно задать свой через `AWG_PORT=…`.

## 2. Установка (одна команда)

```bash
ssh root@<IP-сервера>

apt-get update && apt-get install -y git
git clone -b claude/vpn-server-netherlands-a5dmiz https://github.com/efim-armand-ai/ai-prompt-builder-bot.git
cd ai-prompt-builder-bot/server

ADMIN_USER=dev \
VPN_DEVICES="iphone1 iphone2 iphone3 ipad1 ipad2 ipad3 pixel laptop pc" \
AWG_PEERS="home-router" \
bash setup.sh
```

> После слияния ветки в `main` флаг `-b claude/vpn-server-netherlands-a5dmiz` можно убрать.

Скрипт по очереди:
1. **Защищает сервер.** Создаёт пользователя `dev` с sudo по паролю. Включает вход только по ключу, запрещает вход под root. Настраивает файрвол (открыты только SSH и 443), fail2ban, автообновления безопасности, BBR и swap.
2. **Ставит VPN.** Устанавливает Xray с VLESS + Reality и создаёт по устройству на каждое имя из `VPN_DEVICES`, с QR-кодами.
3. **Ставит AmneziaWG для роутера.** Модуль ядра из PPA Amnezia, пир `home-router` с конфигом и QR-кодом. Если на этом шаге скрипт попросит перезагрузку (обновилось ядро), выполни `sudo reboot`, затем `sudo bash /opt/vps-setup/setup.sh`. Повторный запуск безопасен.
4. **Ставит Claude Code.** Устанавливает его для пользователя `dev` и добавляет команды `claude-remote` и `claude-shell`.

В конце скрипт печатает **пароль для sudo**. Сохрани его в менеджер паролей.

Необязательные настройки (переменные перед `bash setup.sh`):

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `ADMIN_USER` | `dev` | Имя твоего пользователя |
| `SSH_PORT` | `22` | Порт SSH. Нестандартный порт уменьшает шум в логах |
| `VPN_DEVICES` | `device1` | Устройства для VPN через пробел |
| `VPN_PORT` | `443` | Порт VPN. Лучше оставить 443 |
| `REALITY_SNI` | `www.microsoft.com` | Сайт, под HTTPS-трафик которого маскируется VPN |
| `AWG_PEERS` | `home-router` | Пиры AmneziaWG (роутеры) через пробел |
| `AWG_PORT` | случайный 20000–60000 | UDP-порт AmneziaWG |
| `SKIP_AWG` | — | `1`: не ставить AmneziaWG |
| `CLONE_REPO` | — | Git-репозиторий, который склонировать в `~/projects` |
| `SKIP_CLAUDE` | — | `1`: не ставить Claude Code |

Шаги можно запускать и по отдельности: `01-harden.sh`, `02-vpn.sh`, `03-amneziawg.sh`, `04-claude-code.sh`. Все скрипты можно перезапускать: ключи VPN и устройства сохраняются. `setup.sh` копирует скрипты в `/opt/vps-setup`, чтобы они были доступны пользователю `dev` для обслуживания (клон в `/root` ему не виден).

## 3. Проверь вход ДО закрытия окна

Вход под root по SSH уже отключён. В **новом** окне терминала:

```bash
ssh dev@<IP-сервера>          # или: ssh -p <SSH_PORT> dev@<IP>
sudo whoami                   # спросит пароль из шага 2 и ответит root
```

Только когда это сработало, закрывай старое окно.

## 4. VPN: какое устройство через что

| Устройства | Как подключаются | Почему |
|---|---|---|
| iPhone ×3, iPad ×3, Pixel, ноутбук | Приложение VLESS + Reality на самом устройстве | Работает везде: дома, в мобильной сети, в чужом Wi-Fi. Это самый устойчивый к блокировкам протокол |
| ТВ-приставки ×2 | Через домашний роутер (AmneziaWG) | На приставку ничего ставить не нужно |
| Компьютер | Через роутер, если он всегда дома. Иначе приложение VLESS (профиль `pc`) | |

У каждого устройства свой ключ. Потерял телефон: `sudo vpn remove iphone2`, остальные устройства продолжают работать.

```bash
sudo vpn add ipad4      # новое устройство: ссылка + QR-код прямо в терминале
sudo vpn show iphone1   # показать ещё раз
sudo vpn link iphone1   # только ссылка (скопировать и отправить себе)
sudo vpn list           # все устройства, включая роутер
sudo vpn remove iphone2 # отключить устройство
sudo vpn status         # состояние сервера и handshake роутера
```

Клиенты (все умеют VLESS + Reality и импорт по ссылке или QR):

| Платформа | Приложения |
|---|---|
| iPhone / iPad / Mac (M1+) | Streisand, v2RayTun, Happ, FoXray |
| Android | v2rayNG, Hiddify, Happ |
| Windows | Hiddify, v2rayN |
| Linux | Hiddify |

В приложении нажми «+», затем «Импорт из буфера» или «Сканировать QR» и включи подключение. Проверка: [ifconfig.me](https://ifconfig.me) должен показать IP сервера.

### 4.1 Домашний роутер: Keenetic / Netcraze (Challenger SE)

**Какая прошивка нужна.** Сервер использует параметры маскировки AmneziaWG 1.0 (`Jc/Jmin/Jmax/S1/S2/H1–H4`). Их понимает штатный компонент WireGuard в стабильной KeeneticOS/NetcrazeOS 4.3 и новее. Поэтому для этого сервера **не нужны** ни канал разработчика (там нативный AWG 3.x, начиная с 5.2 Alpha 11), ни Entware с AWG Manager. Оставайся на стабильной прошивке. Версию смотри на главной странице веб-интерфейса.

**Шаги** (названия пунктов меню могут немного отличаться между версиями):

1. **Компонент.** «Общие настройки» → «Изменить набор компонентов» → включи **WireGuard VPN** → «Установить обновление». Роутер перезагрузится.
2. **Конфиг.** Сохрани его на сервере и забери на ноутбук:
   ```bash
   # на сервере, под dev:
   (umask 077; sudo vpn link home-router > ~/home-router.conf)
   # на ноутбуке:
   scp dev@<IP-сервера>:home-router.conf .
   # на сервере, после импорта:
   rm ~/home-router.conf
   ```
3. **Импорт.** «Интернет» → «Другие подключения» → «WireGuard» → **«Загрузить из файла»** → `home-router.conf`. Включи подключение и поставь галочку «Использовать для выхода в интернет»: без неё подключение не появится в политиках.
4. **Проверь маскировку.** `sudo vpn show home-router` печатает готовую команду `interface Wireguard0 wireguard asc …` с твоими значениями. Если после импорта параметры не подхватились (в `sudo vpn status` нет handshake), выполни эту команду в веб-CLI роутера (`http://192.168.1.1/a`, номер `WireguardN` смотри в списке подключений), затем `system configuration save`.
5. **Только ТВ-приставки в туннель:**
   - «Список устройств» → зарегистрируй обе приставки (и компьютер, если нужно);
   - «Приоритеты подключений» → «Добавить политику», например `VPN`. В ней оставь включённым **только** подключение WireGuard, основное подключение провайдера выключи;
   - в той же политике (вкладка «Применение политик» или в карточке устройства) назначь приставкам политику `VPN`. Остальные устройства остаются в политике по умолчанию, то есть идут напрямую.

   Плюс такой политики: если туннель упадёт, приставки останутся без интернета, а не уйдут молча в обычную сеть.
6. **Проверка.** `sudo vpn status` показывает свежий handshake у `home-router`. В браузере приставки [ifconfig.me](https://ifconfig.me) показывает IP сервера.

Почему не вся сеть через туннель:
- iPhone и iPad со своим VLESS иначе окажутся в двойном туннеле;
- местные банки и госсервисы часто не пускают зарубежные IP;
- у VPS есть месячная квота трафика. 4K-стриминг — порядка 7 ГБ в час на приставку.

**DNS.** Приставки спрашивают DNS у роутера, а роутер по умолчанию — у провайдера. Если сервисы на приставке ведут себя так, будто VPN нет, включи на роутере DNS-over-HTTPS или DNS-over-TLS (компоненты с такими названиями) с публичным сервером, например 1.1.1.1.

**Если провайдер научится блокировать AWG 1.0.** Первое средство — параметр `I1` (сигнатурный пакет перед handshake). Он задаётся только на клиенте, сервер менять не нужно. Начиная с прошивки 5.1 его можно добавить в настройки подключения на роутере. Пользователи Keenetic сообщают, что работают простые варианты вроде `I1 = <r 64>`.

## 5. Claude Code: работа с телефона

Один раз, зайдя по SSH как `dev`:

```bash
claude                 # набери /login → открой ссылку на телефоне/ноутбуке,
                       # войди подпиской Claude, вставь код обратно → /exit
claude-remote          # ответь y на «Enable Remote Control?» и «Trust …?»
                       # нажми пробел → QR-код → отсканируй телефоном
                       # выйти из tmux, не останавливая Claude: Ctrl+B, затем D
sudo systemctl enable claude-remote   # поднимать Remote Control после перезагрузки
```

Дальше SSH не нужен: открой приложение Claude, раздел **Code**, и выбери сессию сервера. Команды выполняются на сервере, в папке `~/projects`.

Запасной путь через SSH (Termius или Blink на телефоне):

```bash
claude-shell           # Claude Code в tmux; связь оборвалась → зайди снова и набери claude-shell
```

Добавить ключ телефона на сервер: скопируй публичный ключ из Termius или Blink, затем выполни на сервере `nano ~/.ssh/authorized_keys`, вставь ключ новой строкой и сохрани.

## 7. Безопасность

- Пароль для sudo нужен специально. Claude Code работает под `dev` и **не может** молча выполнить `sudo`: пароль он не знает. Не делай `NOPASSWD` и не запускай Claude под root.
- Не запускай Claude с `--dangerously-skip-permissions`, пока на сервере лежат ключи и токены, которые жалко потерять.
- `/usr/local/etc/xray/reality.env`, `config.json` и `/etc/amnezia/amneziawg/` содержат приватные ключи VPN. Никому их не отправляй. Конфиг роутера после импорта удали из домашней папки.
- Все секреты создаются на сервере. В репозитории их нет, поэтому скрипты можно держать публичными.

## 8. Если что-то не работает

| Симптом | Что делать |
|---|---|
| VPN подключается, но сайты не открываются | Переимпортируй свежую ссылку (`sudo vpn show <имя>`): после смены ключей или сайта маскировки старые ссылки не работают |
| VPN не подключается вообще | `sudo vpn status`, `sudo journalctl -u xray -n 50`. Проверь облачный файрвол провайдера (443/tcp) |
| VPN работает дома, но не в мобильной сети (или наоборот) | Смени сайт маскировки: `sudo REALITY_SNI=www.apple.com bash /opt/vps-setup/02-vpn.sh`. Ссылки устройств поменяются, импортируй их заново через `sudo vpn show <имя>` |
| Соединение «замирает» после первых килобайт | Сеть, из которой ты подключаешься, режет диапазон IP этого хостинга. Помогает только сервер у другого провайдера |
| Роутер не подключается (в `sudo vpn status` нет handshake) | Открой UDP-порт AmneziaWG (`sudo vpn awg-port`) в облачном файрволе провайдера. Переимпортируй конфиг целиком. Если твой интернет-провайдер режет UDP, пускай устройства через VLESS |
| Keenetic: подключение WireGuard «включено», но handshake нет | Проверь, что маскировка применилась (шаг 4 раздела 4.1), и что UDP-порт открыт у провайдера VPS. Проверь прошивку: нужна 4.3+ |
| Приставка в политике `VPN` без интернета | Туннель не поднят (нет handshake), либо в политике не включено подключение WireGuard |
| `03-amneziawg.sh`: «Модуль ядра amneziawg не загрузился» | `sudo reboot`, затем `sudo bash /opt/vps-setup/setup.sh` |
| Потерял доступ по SSH | Веб-консоль провайдера (VNC/Console) → войди под root → проверь `/etc/ssh/sshd_config.d/00-hardening.conf` |
| `claude-remote` пишет об ошибке входа | Выполни `claude`, затем `/login`. Нужен вход подпиской Pro/Max, а не API-ключом |
